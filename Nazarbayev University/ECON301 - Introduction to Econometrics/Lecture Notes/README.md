## R examples

I group scripts with the corresponding lecture where the connection is clear, and keep general routines under supplementary scripts. Shared scripts are linked across offerings. Depending on the example, packages include `wooldridge`, `tidyverse`, `dplyr`, `sandwich`, `lmtest`, `stargazer`, and `car`. Some scripts are helper routines intended to be used with other examples.
